PaddleUp — Design System
PaddleUp Design System
v0.1 · tokens, components, states · source of truth for build agents
Inline styles + CSS variables
Every colour is a var(--token). Theme (light/dark) and franchise colour are swapped by rewriting variables on the app root.
Two colour worlds
Outside a room (auth, home hub) the shell is brand coral. Inside a room, your franchise colour takes over: header, primary actions, tints.
Sport-agnostic UI
Role chips, stat names, currency and units are rendered from the Sport Pack. Cricket T20 values here are pack data, never hard-coded (NFR-12).

03

Franchise palette

12 colours, equal lightness and chroma, 30° apart: oklch(0.56 0.15 h). White text passes 4.5:1 on every solid. Picked at franchise creation; unique per room.

Each colour derives 6 tokens: --team, --team-strong, --team-tint, --team-tint-2, --team-ink, --on-team, --room-bg.
